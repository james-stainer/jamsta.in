Selected work

Forecasting vital signs in paediatric intensive care

PhD thesis, UCL and Great Ormond Street Hospital

I used a PyTorch StemGNN model to forecast heart rate and blood pressure together from 5-second bedside-monitor data, treating the dependencies between them as a learned graph.

I also built the clinical time-series pipeline behind it, which took 4,120 raw admissions down to 364 high-quality patients and about 12.5M observations. It covers age-aware normalisation, missing data, outlier detection and sliding-window segmentation.

DrugnomeAI: predicting which human genes can be drugged

With AstraZeneca's Centre for Genomics Research. Published in Communications Biology, 2022

An ensemble machine-learning framework that scores all 19,846 human protein-coding genes for druggability, using 324 features from 15 sources. Specialised models are stratified by drug modality (small molecule, antibody, PROTAC) and by therapeutic area.

Top-ranked genes were significantly enriched for targets already in clinical development, and for genome-wide significant hits in a UK Biobank PheWAS of 450K participants. The framework outperformed three published benchmarks.

Adversarial evaluation of frontier AI agents

Freelance, current

I write hard bioinformatics and scientific coding tasks that benchmark how frontier LLM agents reason, each with a reference solver, a grading contract and a deliberate reasoning trap. I then audit the agent transcripts for answer leakage, shortcuts and data bugs, so a failure means the model got it wrong and not that the task was broken.
